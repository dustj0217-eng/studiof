# Potion Online — Endless Shop Skeleton v2

이번 골격의 목표는 **엔딩/Day 기반이 아닌 장기 운영형 포션샵**으로 게임 구조를 바꾸는 것입니다.

## 현재 들어간 핵심 골격

- Day 표시 제거 → Shop Level / XP 기반 장기 성장
- 주문 완료/거절 후 새 주문 자동 보충 → 주문함이 계속 순환
- 주문 상세에서 추가 상담 질문 가능
- 상담 자원은 배송할 때 조금씩 회복
- 재료가 실제 재고로 동작하고 제조/배송 시 1개씩 소비
- 운영 탭에서 재료 도매 구매 가능
- 비밀 조합 발견 시 레시피 도감 영구 해금
- 주문 만족도/비밀 조합에 따라 Shop XP 획득
- 레벨 6 이후에도 350XP 단위로 명성 레벨 무한 상승
- localStorage 자동 저장 (`moncity:potion-online:v2`)

## 이 버전에서 의도적으로 아직 안 만든 것

이 파일은 '완성 버전'이 아니라 이후 시스템을 붙이기 위한 골격입니다.

- 단골 고객별 장기 스토리
- 주문 문장 조합식 생성기
- 지연 리뷰/배송 시간
- 재료 시세 변동/공급처
- 가게 장비 업그레이드
- 특수 주문/이벤트
- 고객 성향/정직도/거짓말
- 꾸미기/직원/경쟁점

## 다음 권장 개발 순서

1. 주문 변형 생성기 (같은 효과라도 사용 상황이 다르게)
2. 단골 고객 상태/연속 주문
3. 리뷰 지연 + 재주문
4. 재료 시장 변동
5. 장비/가게 업그레이드
6. 희귀/특수 주문

핵심 원칙: **새 기능보다 먼저 주문 하나를 읽고 판단하는 재미를 키운다.**
