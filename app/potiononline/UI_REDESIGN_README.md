# POTION ONLINE — MOBILE SELLER UI REDESIGN GUIDE

> 목표: **“게임 UI”가 아니라, 플레이어가 마야의 스마트폰으로 실제 포션 쇼핑몰을 운영하는 느낌**
>
> 방향: **모바일 쇼핑몰 관리자 앱 70% + 키치 마법소녀 / 레트로 뉴트로 30%**
>
> 핵심 원칙: 플레이어는 메뉴를 조작하는 사람이 아니라 **마야 본인**이다.

---

## 0. 이번 UI 리디자인에서 지킬 것

- 세로형 모바일 기준. 현재 `.potion-root` 최대 폭 `430px` 유지 가능.
- 화면을 판타지 게임 HUD처럼 만들지 않는다.
- 주문, 문의, 리뷰, 재고, 발주가 **실제 셀러 앱처럼 보여야 한다.**
- 별/하트/리본/홀로그램/스티커는 장식 레이어로 사용하고, 정보 구조는 현실 앱처럼 단순하게 유지한다.
- 큰 금장 프레임, RPG 인벤토리 창, 양피지 UI는 줄인다.
- 한 화면에 너무 많은 기능을 넣지 않는다. **리스트 → 상세 → 행동**의 모바일 앱 흐름을 우선한다.
- 상태 변화는 `대기 / 상담중 / 제작중 / 배송완료`처럼 쇼핑몰 주문 상태처럼 보여준다.
- 마야의 개성은 색, 문구, 스티커, 알림, 작은 낙서에서 드러내고 기능성은 희생하지 않는다.

# 1. UI를 고칠 때 가장 먼저 보는 파일

## `game/potion.css`

**게임 전체 UI 톤을 바꾸는 1순위 파일.**

현재 여기에서 다음을 관리한다.

- 전체 배경
- 전역 폰트 변수
- 컬러 변수
- 모바일 최대 너비
- 공통 애니메이션
- 버튼 기본 리셋
- 스크롤 동작

현재 팔레트는 갈색/양피지/금색 중심이다.

# 3. 상단 — “게임 HUD”에서 “셀러 앱 헤더”로

```text

```

검은 배경 + 금색이라 판타지 HUD에 가깝다.

### 새 방향


**고칠 것:**

- 검정/금색 제거

# 5. 주문 홈 / 주문 리스트

## `game/components/shop/ShopPage.tsx`

**주문 화면 전체 레이아웃.**

현재 포함 요소:

- Maya's Potion Shop 히어로 배너
- 평점/배송/가게 레벨
- 제작 중 알림
- 카테고리 칩
- 정렬
- 주문 카드 리스트
- 세계 변화 현황

### 가장 먼저 수정할 부분

현재 큰 검은 히어로 배너는 **쇼핑몰 판매자 앱 대시보드 카드**로 바꾼다.

예:

```text
안녕하세요, 마야 ✦
새 주문이 6건 들어왔어요.

[대기 6] [상담 2] [제작 1] [배송 3]
```

그 아래부터 바로 주문 리스트.

`세계 변화 현황`은 홈 첫 화면에 항상 노출하기보다 나중에 `인사이트/리포트` 형태로 이동하는 것을 권장한다.

### 키치 포인트

- `NEW ORDER` 홀로그램 씰
- 단골 = 하트 스티커
- 긴급 = 번개 배지
- 위험 = 보라 경고 씰
- 프로모션 배너는 2000년대 쇼핑몰 광고 배너처럼 약간 촌스럽고 귀엽게

```text
제작 주문 #PO-1842
김별 · 집중 포션
```

# 9. 게임 로직과 UI를 헷갈리지 말 것

아래 파일은 **외형만 바꿀 때는 되도록 건드리지 않는다.**

```text
game/lib/gameStore.tsx
game/lib/gameEngine.ts
game/lib/gameData.ts
game/systems/orderSystem.ts
game/systems/consultationSystem.ts
game/systems/inventorySystem.ts
game/systems/progressionSystem.ts
game/systems/recipeSystem.ts
game/types/potion.ts
```

역할:

- `gameStore.tsx` — 현재 게임 상태와 dispatch
- `gameEngine.ts` — 포션 결과 계산
- `gameData.ts` — 재료/주문/레시피 데이터
- `systems/*` — 주문/상담/재고/성장 시스템
- `types/potion.ts` — 타입 정의

**색, 카드, 여백, 폰트, 탭 디자인을 바꾸는 데 이 파일들은 필요 없다.**

단, `문의` 탭을 새로 추가하거나 주문 상태를 `상담중/제작중/배송중` 등으로 확장할 때는 상태 타입과 store 수정이 필요하다.

# 10. 현재 UI 코드에서 알아둘 점

현재 컴포넌트 대부분은 **CSS Module이 아니라 각 TSX 파일 내부 `<style jsx>`**를 사용한다.

따라서:

```text
TopHeader 디자인 → TopHeader.tsx
BottomNav 디자인 → BottomNav.tsx
주문 화면 디자인 → ShopPage.tsx
주문 카드 디자인 → OrderCard.tsx
주문 상세 → OrderModal.tsx
제작 화면 → CraftPage.tsx
결과 화면 → ResultModal.tsx
리뷰 화면 → ReviewsPage.tsx
운영 화면 → ManagePage.tsx
```

를 각각 열어서 하단 CSS를 수정해야 한다.

**전역 색상/배경/공통 토큰만 `potion.css`에서 관리한다.**

# 11. 추천 리팩터링 — UI를 계속 고칠 거라면

추천 구조:

```text
game/
├─ ui/
│  ├─ tokens.css
```

# 14. 마야 몰입감을 만드는 UI 문구

게임식:

```text
퀘스트 완료
아이템 획득
경험치 +20
```

보다 셀러 앱식:

```text
신규 주문이 도착했어요.
고객이 답장을 보냈어요.
재고가 2개 남았어요.
상품 제작이 완료됐어요.
배송 처리가 완료됐어요.
새 리뷰가 등록됐어요.
```

를 사용한다.

플레이어에게 “게임을 하고 있다”보다 **“마야의 업무 알림을 보고 있다”**는 인상을 줘야 한다.

# 15. 첫 UI 개편 작업 순서

1. `potion.css` — 전체 팔레트와 배경 변경
2. `TopHeader.tsx` — 셀러 앱 헤더로 변경
3. `BottomNav.tsx` — 실제 모바일 앱 탭처럼 변경
4. `ShopPage.tsx` — 대시보드 + 주문 리스트로 변경
5. `OrderCard.tsx` — 쇼핑몰 주문 카드로 변경
6. `OrderModal.tsx` — 주문 상세 페이지/바텀시트로 변경
7. `CraftPage.tsx` — 제작 도구 앱 스타일
8. `ResultModal.tsx` — 상품 제작 완료 화면
9. `ReviewsPage.tsx` — 쇼핑몰 후기 UI
10. `ManagePage.tsx` — 셀러센터/발주 화면

**이 순서를 권장한다.** 1~6까지만 바꿔도 게임 첫인상은 완전히 달라진다.

# 16. 절대 잊지 않을 기준

UI를 보고 아래 질문에 YES가 나와야 한다.

> 이 화면을 스크린샷만 봤을 때 판타지 RPG의 메뉴가 아니라 모바일 쇼핑몰 앱처럼 보이는가?

> 플레이어가 “마야를 조종한다”보다 “내가 마야의 폰으로 내 포션샵을 운영한다”고 느끼는가?

> 마법소녀 감성이 기능을 방해하지 않고, 실제 앱 위에 마야 취향이 묻어난 것처럼 보이는가?

세 질문 모두 YES면 방향이 맞다.

## 현재 단계

이 ZIP은 **UI 리디자인을 시작하기 전에 어디를 수정해야 하는지 명확히 하기 위한 기준판**이다.
